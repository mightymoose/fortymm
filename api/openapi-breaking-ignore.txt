# Deliberate breaks to /v1 that openapi:breaking lets through, one per line,
# as oasdiff prints them: METHOD PATH description. Only the lines a change adds
# count, so each one covers only the change that adds it. Allowed only until
# the first app release (see OpenAPI schema and clients in api/CLAUDE.md).
# #59: a verified account can have no self player while "Is this you?" waits.
POST /v1/session the `data/account/player` response's property `type` changed from `object` to `any` for status `200`
POST /v1/session removed the required property `data/account/player/display_name` from the response with the `200` status
POST /v1/session removed the required property `data/account/player/id` from the response with the `200` status
POST /v1/session added `#/components/schemas/SessionPlayer, subschema #2` to the `data/account/player` response property `anyOf` list for the response status `200`
# The models write a nullable as `type: [X, "null"]`, not `anyOf`, for the iOS
# client's generator. oasdiff reads that as removing `null`, but it means the same.
POST /v1/account/players/{player_id}/answer request property `player_id` list-of-types was narrowed by removing types `null` from media type `application/json`
# #185: the logout body is optional with no `null` branch, which
# swift-openapi-generator skips. A body of `null` now answers 422. No client
# sends one, and the web client sends no body.
POST /v1/auth/logout the request's body `type` changed from `any` to `object`
POST /v1/auth/logout removed `#/components/schemas/LogoutRequest, subschema #2` from the request body `anyOf` list
# guests on the admin Accounts page
GET /v1/admin/accounts the response property `data/items/email` became nullable for the status `200`
GET /v1/admin/accounts/{account_id} the response property `data/email` became nullable for the status `200`
PUT /v1/admin/accounts/{account_id}/roles the response property `data/email` became nullable for the status `200`
