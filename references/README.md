# References

Material the app is built against. Nothing here is built, linted or deployed.

- `deprecated/`: references the app is moving away from. The app still matches
  them until the move ends.
  - `fortymm-design-system/`: the deprecated FortyMM design system as
    exported. Start with its `README.md` (brand, voice, visual foundations)
    and `colors_and_type.css` (design tokens); `ui_kits/` and `preview/` hold
    the component demos.
- `fortymm-design-system-v2/`: version 2.1 of the FortyMM design system, as
  copied from its Claude Design project. Start with its `README.md` and
  `colors_and_type.css`. `ui_kits/components/` holds the component library,
  and `ui_kits/tournament/` holds the screens built from it.
