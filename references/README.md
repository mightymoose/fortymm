# References

Material the app is built against. Nothing here is built, linted or deployed.

- `design-system/`: version 2.1 of the FortyMM design system, as
  copied from its Claude Design project. The app matches it. Start with its
  `README.md` and `colors_and_type.css`. `ui_kits/components/` holds the
  component library, and `ui_kits/tournament/` holds the screens built from
  it. The app's `/design-system` page is a copy of
  `ui_kits/components/index.html`.
- `matches.md`: how a match is recorded, from the scratchpad to a
  settled result, and why the rules are what they are.
