# Sample slides — FortyMM deck template

Seven sample slide types, all 1920×1080, using the deck-stage web component:

1. **Title** — hero lockup + dot-grid
2. **Section header** — chapter marker + display type
3. **Big metric** — a single number doing all the work (mono)
4. **Comparison** — FortyMM vs. the others, two-column
5. **Quote** — giant quotation mark + brand tagline
6. **Scoreboard** — live match score, full-bleed broadcast feel
7. **Closing** — hero repeat with URL

Copy-paste any `<section>` into your own deck. Arrow keys to navigate.
