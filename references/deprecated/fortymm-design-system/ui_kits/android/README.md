# Android UI kit

Visual twin of the iOS kit with Material-ish adjustments: Roboto fallback, FAB for primary action, M3-style bottom nav pill indicators. Same tokens, same colors, same voice.

- `android-frame.jsx` — starter frame
- `screens.jsx` — `AHome`, `ATopBar`, `ABottomNav`, `AFab`
- `index.html` — single-screen demo
