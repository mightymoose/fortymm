# iOS UI kit

FortyMM for iOS (dark-mode only).

- `ios-frame.jsx` — device frame scaffold (from starter components)
- `screens.jsx` — FortyMM-branded `HomeScreen`, `BracketScreen`, `ProfileScreen`, `TabBar`, `TopBar`, and sub-components
- `index.html` — click-through demo with tab switcher

Conventions used here translate directly to Android via the Material components — visual language is identical (dark ink, orange accent, mono numerals).
