# Web admin UI kit

Tournament control dashboard. This is where directors run tournaments.

- `components.jsx` — `Sidebar`, `ActionBar`, `StatStrip`, `CourtGrid`, `CourtCard`, `SolverPanel`
- `index.html` — live courts view with SMT-solver panel

The solver panel is a first-class surface. Most tournament apps hide the scheduling engine — we show ours, because it's the product differentiator.
