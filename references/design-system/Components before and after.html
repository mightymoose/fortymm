Components: before and after

v2 calmed the system down; v2.1 gives each component its own structure so roles are recognisable at a glance. Left is v2 as shipped, right is v2.1 from the shared kit.css.

Visual only · examples are static

Tooltip

The white tooltip was the brightest thing on screen — brighter than the score. Now it's the dark raised surface with a quiet edge and a smaller shadow, wraps at 280px, and appears on keyboard focus too.

Toast

The toast shared a panel's fill, border and padding, and looked identical to an in-page alert. Now it's a single compact line on the raised surface with the overlay shadow, a green check, Undo as the action and a dismiss button. Errors moved out of toasts entirely.

Card

The panel was a bordered box with a grey label as its heading and every line at a similar weight. The card has a real title, status at the top right, details grouped as label/value pairs, the rest time as an inline notice, and actions in a footer with the primary first.

Fields

Field and checkbox edges were the same grey as dividers, and a focused invalid field lost its red edge to the orange ring. Edges now use --border-field (3:1); errors add a 2px red edge, an icon and a fix, and keep all three while focused. Disabled fields have one consistent look.

Buttons

Loading used the disabled style, so "Saving…" was dim grey; disabled primary buttons still lit up on hover. Loading now keeps its colours with a static ring; disabled looks the same under the pointer; secondary edges are brighter.

Match row

Games won and current points sat side by side in similar mono type, so "1 8" read as one number. Games are now a boxed tally, points stay large, both columns are labelled, the full game history opens from a tap target, and long names wrap.
