# Sample slides

Seven 1920×1080 slide types on the `deck-stage` component, built from `colors_and_type.css`:

1. **Title** — event and purpose, wordmark in the footer
2. **Section** — panel background, plain heading
3. **Big number** — one figure in mono with the sentence that explains it
4. **Comparison** — before/after in divider rows, no highlighted "hero" column
5. **Quote** — text only, no giant quotation mark
6. **Venue scoreboard** — Bebas surnames, mono scores, white serve marker, static Live marker
7. **Closing** — next step in plain words

Copy any `<section>` into your own deck. Arrow keys to navigate.
