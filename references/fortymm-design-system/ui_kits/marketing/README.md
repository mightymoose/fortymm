# Marketing site UI kit

Public landing page for fortymm.com. Dark-mode only (this is not a "both themes" product).

- `index.html` — composed page: Nav, Hero with live scoreboard, Manifesto, Footer
- `components.jsx` — `Nav`, `Logo`, `Hero`, `Manifesto`, `Footer`, `Stat`, `HeroScoreboard`

Uses tokens from `../../colors_and_type.css`. The page leads with the tagline **"Play more. Pay never."** and the anti-SaaS manifesto is half the page — that's intentional, not decoration.
