FortyMM component showcase

Reference page for screenshot tests. Every component in the v2.1 library, in its documented states, built from the shared tokens and fm-* classes. Test ids match the component gallery, so the same Playwright selectors work against the app.

Everything here is visual only. Overlays, open menus and forced hover, focus and pressed states are drawn in place so each one can be captured without interaction.

Foundations

Dark only, flat surfaces. Orange marks actions and selection; every status has its own hue and a non-colour cue.

Surfaces
